## EP05 — Building Software With Claude and AI (10:00)

Core question: How do you use AI to build software without handing over your judgement?

Cover:
- Write a clear product brief.
- Define user, problem, requirements, and user journey.
- Inspect the existing repository before changing code.
- Ask for a plan before implementation.
- Break work into small tasks.
- Review changes and test the actual flows.
- Use version control.
- Test different user accounts.
- Treat AI output as work to inspect, not truth.
- Learn technical concepts as you build.
